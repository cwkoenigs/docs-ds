Docs shell

This site renders whatever content tree it is pointed at.

Point it at a staged tree with DOCS_CONTENT_PATH and it renders that tree with pointers resolved, standards as pages, and local search.

npm startDOCS_CONTENT_PATH=/path/to/stage/docs SITE_BASE_URL=/ npm run buildnpm run validate
