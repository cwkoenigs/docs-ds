The shared record of the Data Science team's work.

## Browse the wiki

- [Projects](projects/index.md): project context and related work.
- [Changelog](changelog.md): changes recorded across repositories.
- [Insights](insights/index.md): findings and lessons learned.
- [Apps](apps/index.md): the application catalog.
- [Architecture decisions](adr/index.md): decision records and a reusable template.
- [Cross-repo ADR registry](adr-index.md): links to decisions owned by other repositories.

## Contribute

Write standard Markdown. Add `title` and `sidebar_position` in YAML frontmatter to control page titles and navigation order. Project pages can also include `tags` and `related` arrays.

The `ds-changes` skill writes project updates, changelog entries, insights, and registry rows into this wiki. These paths are preserved for the migration.
